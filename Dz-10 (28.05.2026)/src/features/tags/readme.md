# Модуль Тегів

Цей модуль відповідає за управління тегами для постів у соціальній мережі.

### Основні можливості:

- **Групування постів**: Авторизовані користувачі можуть додавати теги до постів для їхньої категоризації та пошуку.
- **Зв'язок багатьох до багатьох**: Один пост може мати кілька тегів, а один тег може належати багатьом постам.
- **Збереження цілісності**: При видаленні поста видаляються лише його зв'язки з тегами, самі теги залишаються в базі даних.

### Технічні деталі:

- **Модель**: `Tag` з полями `id` та `name`
- **Таблиця зв'язку**: проміжна таблиця зв'язку `post_tags` з полями `post_id` та `tag_id`.
- **API**:
  - `POST /tags/{post_id}` — додавання тегів до посту.

### Стандарти:

- Використовується асинхронна робота з БД через SQLAlchemy 2.0.
